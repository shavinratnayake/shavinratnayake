## Featured Projects

### Synchronous FIFO Verification

Parameterized synchronous FIFO with a class-based SystemVerilog verification environment.

- Constrained-random stimulus
- Reference-model scoreboard
- SystemVerilog Assertions (SVA)
- Functional and cross coverage
- Overflow, underflow, and boundary testing
- Read/write pointer wraparound verification
- 100% functional coverage (26/26 bins)
- 100% pointer wrap coverage (2/2 targets)
- 4,479 checks passed with zero failures

The verification environment also exposed an RTL count-logic bug during constrained-random testing, which was debugged, corrected, and verified through regression.

### UART Transmitter Verification

SystemVerilog UART transmitter with a class-based, self-checking verification environment.

- Constrained-random 8-bit transactions
- Generator, driver, monitor, and scoreboard architecture
- SystemVerilog interface and clocking blocks
- SystemVerilog Assertions (SVA)
- Functional coverage across the 8-bit data space
- 100% functional coverage (12/12 bins)
- 1,000 transactions passed with zero failures
